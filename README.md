# Network Packet Capture & Protocol Analysis

## Overview
This lab documents network traffic analysis performed using Wireshark to inspect packet structures, protocol handshakes, and database query security.

## Key Highlights
- Captured and analyzed 500+ network packets across TCP/IP layers.
- Inspected TCP 3-Way Handshake (`SYN`, `SYN-ACK`, `ACK`) and DNS lookup routines.
- Evaluated cleartext HTTP traffic vs encrypted HTTPS SSL/TLS streams.
- Documented PortSwigger SQL Injection (SQLi) lab traffic to study payload mechanisms.

## Tools Used
- **Wireshark**: Packet capturing and display filters.
- **PortSwigger Web Security Academy**: SQLi testing environment.
